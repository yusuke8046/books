# 📚 BookScan 蔵書管理アプリ (v260812) - バーコード ＆ ISBN文字読み取り(OCR) 対応

バーコードが印刷されていない本にも対応するため、**カメラで印刷された「ISBN 978...」の文字列を直接読み取る文字認識（OCR）機能** を搭載した最新バージョン（`app_260812`）です。

---

## 🌟 主な機能

1. **バーコードスキャン ＆ ISBN文字読み取り (OCR)**:
   - **バーコードモード**: 書籍裏面のバーコードをカメラで自動スキャン。
   - **ISBN文字読み取り(OCR)モード**: 奥付や裏表紙に書かれた `ISBN 978-4-XXXX-XXXX-X` の**テキスト文字**をカメラ枠に収めて「テキストを読み取る」をタップすると自動解析。
2. **OpenBD API リアルタイム連携**:
   - ISBN認識後、書影・タイトル・著者名・出版社名・発行日を自動取得。
3. **Googleスプレッドシート（A~G列）自動同期**:
   - **A列**: ISBN
   - **B列**: タイトル
   - **C列**: 著者名
   - **D列**: 出版社名
   - **E列**: 発行日
   - **F列**: **登録日** (`YYYY/MM/DD` 自動記録)
   - **G列**: **処分日** (初期状態は空欄・手動入力枠)

## 🚀 使い方 ＆ セットアップ

### 1. Google Apps Script の設定
1. Googleスプレッドシートを開き、「拡張機能」>「Apps Script」を選択します。
2. `Code_260812.gs` の内容をコピー＆ペーストして保存します。
3. 「デプロイ」>「新しいデプロイ」で **ウェブアプリ**（アクセス権限: **全員**）として公開し、URLを取得します。

### 2. アプリの起動
1. 本アプリの URL（ローカル: `http://localhost:8080/app_260812/index_260812.html` または GitHub Pages URL）にアクセスします。
2. 右上設定（ギア）アイコンをタップし、コピーした GAS URL を貼り付けて保存します。
3. モード切替タブで「バーコード」または「ISBN文字読み取り(OCR)」を選択してスキャンを開始してください。
